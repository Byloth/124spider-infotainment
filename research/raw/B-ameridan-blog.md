## 2. Firmware knowledge (every version string Ameridan's pages mention)

### 2.1 Version-string anatomy (B-03, B-20)
`56.00.521A NA N`: `A` = iteration (hidden; Abarth EU/4A/NA 56.00.530 shipped as iteration **D**), `NA`/`EU`/`4A`(=ADR)/`JP` = region,
`N` = NNG (iGO) nav protocol (all regions except Japan), `M` = Matsukone (Japan only). Shown in Settings > System > About > Version Information.
Firmware ships as two `.up` files per region: `cmu150_<REG>_<ver><iter>_failsafe.up` then `..._reinstall.up` (install failsafe first).
K-hon's "MZD CONNECT VERSION LIST" (images in `pdf/firmware-versions*.png`): "ability to tweak firmware via USB is removed after 59.00.449"; rows marked `*` = "124spider only": 56.00.521 (JP*/EU*/NA*), 56.00.530 (JP*/EU*/ADR*), 59.00.524 (EU*/NA*/ADR*), 59.00.562 (EU*/NA*/ADR*); 70.00.100 (EU/NA/ADR), 70.00.110 (JP).

### 3.1 ID7 autorun — "Preserve your ability to tweak" v1 (B-05, B-03 #backdoor)
- **What**: trezdog/id7's "ID7 autorun + Recovery scripts" — installs `/tmp/mnt/data_persist/dev/bin/autorun` (runs every `*.autorun` in that dir at boot, then executes `run.sh` from `/mnt/sd_nav` or any `/tmp/mnt/sd[a-e]1`), plus recovery folders `00-run-tweaks-from-usb` (udev rule `99-run-tweaks.rules` that re-enables tweaks.sh from USB), `00-update-etc-passwd-if-needed` (re-writes `/etc/passwd` with root `cmu`/`jci` entries — the "credentials" that 70.00.335's `passwdupdate` removes), `00-update-sshd-config-if-needed`, `01-start-sshd-and-open-firewall` (sshd on port 24000, password auth, firewall opened twice 90 s apart). - **Download**: `http://www.mediafire.com/file/0r6pzhongok9h0u/autorun_copy_to_usb.zip` (✅ 200 on 2026-08-23; local copy + SHA256 above). ## 5. Navigation / SD maps (Fiat vs Mazda)

- Fiat nav card: Mopar **68366118AA** (~$400 dealer; eBay/Amazon $30–100 copies were CID-clones, many later flagged "fraudulent" by Toolbox). NA "Fiat Connect" Toolbox site never worked; use the **EU site `124spiderinfotainment.com/navigation-updatemymaps`** (Windows/macOS Toolbox; works for all regions except JP) — **host no longer answers (curl 000, 2026-08-23)**; NNG portal `naviextras.com/shop/portal/home` ✅ 200.
- Lock mechanism: new card has `cardnotused.txt(.sgn)`; on first insertion CMU writes `license/device.nng` (VIN-half-locked) → after 62 mi/100 km VIN-locked; after that clones work in that car (XCOPY `/E /V /G /H /K`, Win32DiskImager; Cal's guide 124spider.org thread 39039); Mazda cards are "set up in a manner that doesn't allow cloning". **Mazda SD cards have never worked in a Fiat** (VIN check), even with Fiat firmware; **on Mazda v70 firmware the Fiat card stops working until the NNG folder is swapped** (§3.4). Map updates are card-side and "independent of the system version" (continue after v70 + fix). Card must match firmware region (NA/EU/ADR).

## 6. Warnings / point-of-no-return statements (as phrased by the blog)

Per market these are identical — the blog treats NA/EU/ADR alike except for which `.up` files and which nav card; JP is out of scope (Matsukone nav, JP-only firmware numbers).

1. **70.00.335+ without id7 (v2) installed beforehand = permanently un-tweakable by USB; "SERIAL CONNECTION WILL NOT EVEN WORK ANYMORE"** (trezdog44 via B-06, 2019-05) — softened later to "only by using the serial interface" (Ameridan 2019–2024, several users did recover via serial + id7 on 335) and, since 2025-05, superseded by the mp3 hack ("all my posts that claim newer firmware versions are not tweakable via USB pre-date the newly discovered mp3 hack"). B-01 still says "For now, be sure to only use firmware 70.00.100" and "you DO NOT want to use … 70.00.335, 70.00.352, or 74.00.230".
2. **id7 must be installed BEFORE upgrading past 59.00.449/before 59.00.502+** — and ≥59.00.502 can't be downgraded below 59.00.502, so a 2018+ car on 59.00.524/562/563 cannot get id7 via USB (serial or mp3 hack only).
3. **Dealers**: "insist that the dealership NOT attempt to update your CMU firmware – nothing good will come of it, and it will break your ability to install tweaks"; real case 2021-04 (Italy): Mazda dealer flashed 70.00.357 during hub install.
4. **Firmware before hardware; old hub during flashing**; "ANY other order and NOTHING will work" (ASH8).
5. **Downgrade = pointless**: no Fiat firmware exists online; downgrading with Mazda firmware keeps nav broken and doesn't restore id7; "If you are going to go through all that trouble, you might as well keep the most recent version."
6. **Fiat AIO 1.51 / v56-era tweaks on v70 break the home screen (CP/AA buttons) → black screen/unresponsive menus**; fix = uninstall via the same package or reflash 70.00.100 + MazdaToFiatV70AIO; use MZD-AIO 2.8.6 "Apps to Resources" on v70. Don't install the AIO Android-Auto tweak on v70.
7. **Memory**: v70 leaves very little rootfs; uninstall Speedometer/AA/CASDK before the Fiat tweak; avoid large animations; "ROOTFS IS 100% FULL" dialog in AIO.
8. **Flashing**: name-brand 8–16 GB FAT32 stick formatted on Windows (Mac adds hidden files); download the two `.up` files individually (zip of folder can corrupt them); failsafe first; **tap brake/clutch every ~20 min** or the CMU sleeps mid-update → brick (fix = SPI flash, §3.9); un-pair all phones first (can't afterwards; BT ID changes to "Mazda"); remove SD card and USB music sticks; pick CP vs AA once.
9. **Black screen after "DISPLAY TOGGLE"** in test mode → `tweaks.sh.black_screen`; ash8's blind commander sequence for factory reset; Nav+Mute 10 s reboot; 6-minute walk-away sleep reset.
10. **Wireless CarPlay** is not achievable on our CMU (needs 74.00.200+ and different hardware); don't flash 74.00.230 for it. 74.00.331 + AIO may disable wireless CP (Mazda context). Only ≤74.00.324 is "tweak-safe".
11. Region-wrong firmware is not discussed as a brick risk on the blog; Ameridan treats flashing the other region's Mazda files as the *intended* way to switch tuner markets (NA↔EU), same hardware. Japan is different (Matsukone).
12. Map updates are over (Dec 2023); don't buy a new card expecting 3 more years (VIN-tied).
