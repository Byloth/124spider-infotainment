From my experience, as long as any install was not fatally interrupted, you can recover by removing tweaks. If any install is interrupted - especially and particularly a firmware upgrade - then the likely only solution is to flash the EPROM: this is a hard core removal of the Entertainment system and is an absolute last resort to throwing it in the trash.
