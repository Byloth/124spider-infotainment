I did pick up the P3.2 and ultimately returned it since it did not work as I hoped. The closer to an OEM experience the better. The P3.2 in an Android box so that OS will startup with your car every time. That is fine if you like that sort of thing. (IE installing apps) but the user experience was not so seamless when using CarPlay.

For reference.
P2.x - Wired only
P3.x - Wireless
USB-C added for fast charge (unknown what the exact voltage is but it would be limited by what the CMU can output)

P3.2 - Andoid Box
+ Can install android apps
+ Wireless Carplay
+ Wireless Android Auto
+ Rotory Knob works
- Shortcut buttons return to Android

I then switched to the P3.1 which gives me USB-C and Wireless CarPlay. (but no wired CarPlay) and this worked quite well and I was good with this route

P3.1 - Wireless CarPlay adaptor
+ Wireless CarPlay
+ Wired Android Auto
+ Rotary Knob works
+ Shortcut buttons work
- No wired CarPlay

Now there is a P3B which caught my eye. Still the "Renwoda Speciality Store" on Aliexpress, so I think they are the manufacturer.
https://www.aliexpress.com/i/3256806563441986.html

P3B - Wireless CarPlay/AA adaptor
+ Wireless CarPlay
+ Wired CarPlay
+ Wireless Android Auto
+ Rotory Knob works
+ Shortcut buttons work
- No wired Android Auto

In the end, I had an opportunity to buy a wireless CarPlay CMU for $100 which was almost a direct swap (needed to trim the corner of the GPS harness on the cable). Now I have an entirely OEM wireless CarPlay setup with the CMU part number of TC3N-66-9C0.

I have also used the Carlinkit boxes (V2.0 - V5.0) and the Ottocast box. The Carlinkit V3 (and up) along with the Ottocast worked pretty well, with the occasional non-connecting issue. These "Renwoda Speciality Store" boxes did seem to be the most reliable and came with the USB cables to do the CarPlay upgrade.
