Reset CMU NOR Flash with RPi

Date: July 19, 2017Author: mzdonline

สรุป : แก้ปัญหา MZD Connect หน้าจอค้าง, บูตไม่ขึ้น

วิธีทำ : รีเซต NOR Chip เซตแอดเดรช 0x1000 เป็น 0 ทำให้ cmu บูตสู่ failsafe partition แล้วจึงติดตั้งเฟิร์มแวร์ใหม่ผ่านยูเอสบี

เครื่องมือ และงบประมาณ :
– Raspberry PI 2 หรือ 3 model B ราคาประมาณ 1200บาท
– IC TEST CLIP 16ขา ราคาประมาณ 250บาท

ซอฟต์แวร์
– flashrom

Raspberry PI

GPIO ใน Raspbery PI(RPi) มี 40ขาเรียง 2แถว มีพอร์ตชนิดต่างอยู่มาก เราต้องการใช้ SPI เริ่มเปิดใช้ผ่านคำสั่ง sudo raspi-config เลือก Interfacing Options เปิด SPI แล้วรีบูต

https://www.raspberrypi.org/documentation/hardware/raspberrypi/spi/README.md

ติดตั้ง flashrom

sudo apt install flashrom

โปรแกรม flashrom

+++สำคัญ+++ ควร backup NOR-flash ก่อนทำคำสั่งใดๆ คำสั่ง backup เป็นไฟล์ชื่อ backup-cmu.bin

 flashrom -r backup-cmu.bin -c "S25FL064A/P" -V -p linux_spi:dev=/dev/spidev0.0

คำสั่งต่อไปนี้ป้อนใน Raspbery PI console

อ่านวิธีทดสอบ loop back เพื่อความแน่ใจว่า RPi พร้อมใช้SPIได้ที่ http://elinux.org/RPi_SPI

โปรแกรม flashrom ส่งคำสั่งทดสอบ NAND/NOR flash

  • คำสั่งตรวจสอบ NOR flash เพื่อทดสอบว่า RaspPI มองเห็นชิป
 flashrom -c "S25FL064A/P" -p linux_spi:dev=/dev/spidev0.0,spispeed=8000
  • คำสั่ง backup NOR flash
 flashrom -r backup-cmu.bin -c "S25FL064A/P" -V -p linux_spi:dev=/dev/spidev0.0,spispeed=8000
  • คำสั่ง reflash ใช้กรณีต้องการกู้ SPI flash ROM
 flashrom -w backup-cmu.bin -c "S25FL064A/P" -V -p linux_spi:dev=/dev/spidev0.0,spispeed=8000

CMU

เว็บไซต์ 2x4logic.com เป็นเว็บที่เผยแพร่ข้อมูลทั้งหมดที่ปรากฏในบทความนี้ มีวิธีทำให้ CPU อยู่โหมด Reset ทำให้ขาต่างๆมีสถานะเป็น High impedance (High-Z) เขาพบขา 29 ทำงานด้วยไฟ 0 (active low) ใช้วิธีต่อกราวด์ 24 (GND) กับขา 29 ถ้าไม่ทำขั้นตอน Reset CPU มีโอกาสทำให้วงจรเสียหายถาวร

ผู้เขียนเลือกวิธีเสี่ยงสูงขึ้นเสี่ยงมาก ผิดหลักวิศวกรรมไฟฟ้า แต่ทำให้งานง่ายขึ้นมาก(ใช้ได้กับเครื่องผู้เขียน ไม่ประกันว่าใช้ได้กับทุกเครื่อง ถือว่าเสี่ยงเพิ่ม) ใช้วิธีไม่จ่ายไฟเลี้ยงให้ CMU และไม่ได้เซตCPUให้อยู่โหมด Reset ในรูปต่อ SPI จาก RPi เข้ากับ Spansion NOR Flash ผ่าน Test clip ผู้เขียนได้ใช้วิธีนี้แล้วมากกว่า 5ครั้ง

1 .ทดสอบเชื่อมต่อกับชิป

 flashrom -c "S25FL064A/P" -p linux_spi:dev=/dev/spidev0.0,spispeed=8000

ทดสอบการเชื่อมต่อ เมื่อการต่อวงจรถูกต้อง ขั้นต่อไปเขียนคำสั่งลง NOR flash ขั้นตอนนี้เป็นขั้นตอนที่เสี่ยงที่สุด

2 .สำรองรอม

 flashrom -r backup-cmu.bin -c "S25FL064A/P" -V -p linux_spi:dev=/dev/spidev0.0,spispeed=8000

3 .ส่งคำสั่ง Reset NOR flash

CMU มี 2 partition เป็น  rootfs กับ fail-safe เมื่อระบบทำงานปกติจะบูทเข้า rootfs การ  Reset CMU NOR Flash with RPi  คือสั่งให้ บูทเข้า fail-safe ด้วยการเซต SPI flash ที่ address 0x1000 เป็น 0x00

ป้อนบน terminal ของ RPi

 echo -ne "\x06" > /dev/spidev0.0
 echo -ne "\x02\x01\x00\x00\x00" > /dev/spidev0.0
 บรรทัดแรก เซต SPI flash เป็นโหมด write enable (0x06) เป็นคำสั่งเฉพาะของชิป spansion S25FL064A
บรรทัดที่สอง ส่งคำสั่งเขียน รูปแบบคำสั่งอธิบายด้านล่าง \x02 คือ 02 ในฐาน16 (ดูคำสั่งใน datasheet ตาราง 9.4)

ที่หน้าจอไม่มีการรายงานใดๆ แต่มีการเขียน flash เสร็จสิ้นแล้วขั้นต่อไป ถอดสายทั้งหมดและต่อ power ให้ CMU ให้อยู่ภาวะปกติและติดตั้งเฟิร์มแวร์โดย copy เฟิร์มแวร์ใส่ USB โปรแกรมจะค้นหาและติดตั้งอัตโนมัติ

ใช้ในกรณี CMU เกิดปัญหา Boot Loop, หน้าจอค้าง ทดลองแก้วิธีอื่นแล้วไม่ได้ผลจึงเลือกวิธีนี้เป็นขั้นตอนสุดท้าย วิธีนี้ผู้เขียนเชื่อว่าเป็นท้ายสุด โอกาสทำพังที่ขั้นตอนนี้สูงพอกับโอกาสแก้ไขสำเร็จ เหมาะสำหรับผู้ที่เข้าใจหลักการทำงานวงจรดิจิตอล วงจรไฟฟ้า
