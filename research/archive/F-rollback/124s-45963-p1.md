## [madfiat] 2025-05-26 (post 647092)
Installing Ameridan’s MazdaToFiatV70AIO.zip to Version 74 also requires some minor edits to the tweaks.sh file to allow for version 74, otherwise it will refuse to install. 
Using a proper text editor (such as NotePad++ which is my recommendation) edit the following:
Line 159: Change “elif [ $_VER -eq 70 ]” to “elif [ $_VER -eq 74 ]”
Line 161: Change “if [ $_VER_EXT -le 100 ]” to “if [ $_VER_EXT -le 324 ]“
Line 653: Change “if [ $COMPAT_GROUP -ne 6 ] || [ $CMU_VER -ne 70 ]” to “if [ $COMPAT_GROUP -ne 6 ] || [ $CMU_VER -ne 74 ]
As you can see all that is changing are the numeric values. There are probably more elegant ways of changing this if making a distributable file, but this is the most expedient if you just need to install.

## [stuclark] 2025-08-08 (post 651176)
There's numerous advantages (as shown in the changelogs) for running V70.00.xxx software, with the much improved USB hub, over v56.00.xxx with the old hub. Specifically there are a lot of bluetooth and system stability fixes.
However, the differences between v70 and v74 are far less compelling. Whilst there's still some fixes, none are as "fundamental". I have cars running both v70 & v74 (using Fiat (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) Nav coding, tweaks etc.) and can't say there's any real advantage to v74.The relative hassle of steps needed to be able to install custom code onto v74 also makes it unappealing as something to recommend from a support perspective.

## [madfiat] 2025-08-08 (post 651223)
On the contrary I believe there's no reason to go through the trouble of upgrading to v70 without going to v74. The changelogs show numerous bugfixes.
The "hassle" of steps to install v74 is literally just editing s couple of version number files in the scripts made by previous members of the community. Anyone who can handle the rest of the upgrade process should be able to do that as well.
The only reason I wouldn't install v74 is if I already had v70 from an older installation and didn't want to touch the CMU at all. But if you're already set up to do the upgrade, no reason not to.
