 V70 & V74 Tweaks without ID7 – No Serial Connection Needed? YES YOU CAN!
 Posted on May 25, 2025 by ameridan under Reference 
 compilation of articles authored by madfiat 
[edited by ameridan]
 Thanks to the method HERE MX-5 Miata Forum – View Single Post – [Guide] ND1/ND2 – Touchscreen in motion on latest FW, No hardware required , we are now able to run any script on the CMU even with the “locked” versions. This includes the MazdaToFiatV70AIO conversion, and the Mazda Tweaks 2.8.6!
 This means you can have V70, (or V74, if you wish) without ID7 and no longer is there any need for the serial connection needed for the subsequent tweaks for Fiat/Abarth branding and FIXED NAVIGATION. I have done this on my own CMU in my 2017 124 Spider that did not have id7 and it works.
 Use the method described in Post 142 to run any script on your thumb drive. Note : 
 ❗   Warning for 74.00.331 ❗ 
Installing AIO tweaks on firmware version  74.00.331  may  disable wireless CarPlay . AIO tweaks are only recommended for versions  74.00.324 and lower .
 Tools Needed:
 1 USB thumbdrive
 1 USB keyboard 
 Steps (tutorial video posted below to follow along):
1) Prepare your USB drive (formatted FAT32) with the contents of GitHub – mzd-evo/mzd-connect-1-root (copy the contents of the folder in the zip to the usb drive root)
2) ALSO copy the contents of Ameridan’s MazdaToFiatV70AIO.zip file to the root of your USB drive. Yes you’re mixing files.
3) Boot up your bland Mazda firmware radio. Remove any installed Nav SD card
4) Insert thumb drive (top slot) and keyboard (bottom slot).
5) Set Audio Source to USB1. It will “play” the mp3 files on the thumb drive. Hint: They’re not really MP3 files. It’s a payload to launch the debug screen.
6) You should see a white screen on the left, and then a minute later a black popup dialog. If you don’t get the popup, tap on “Open Terminal” (not sure if this step is needed). On the black popup, select “Terminal”. You may need to click “Next” first to get that option.
7) Now a hard to read terminal screen opens. The directions in the linked post didn’t work for me as it didn’t want to run the script as described. Following is what worked for me:
8) On your USB keyboard type exactly (note the space after “cd”) and hit enter after each:
 cd /mnt​
cd sdb1​
./tweaks.sh​
 (in case the proper folder is not “sdb1”, after cd /mnt, type ls to display your folders within “mnt”)
 9) Now it will give you some missing directory errors and spam your screen. Don’t worry. It will soon pop up with the standard MazdaToFiatV70AIO menu and you’re off to the races! From this point follow the directions on Ameridan’s blog to answer the prompts. When it reboots you can remove the thumb drive!
 What Next:
 🔴 You can run the Mazda Tweaks 2.8.6 the same way! Just copy the mzd-connect-1-root files to the thumb drive, and overlay those files with the contents of the _copy_content_to_root_of_fat32_usb_stick folder, overlaying those. Then run the tweaks.sh from that as well.
🔴 This method also works with v74, so if you had upgraded to that and found you couldn’t downgrade, here’s your fix. 
 However, you will need to use a text editor (such as NotePad++ which is my recommendation) to edit the run.sh file as follows to prevent AIO version check from aborting on V74 firmware (simply click Edit > Find to search for it and Save after changing the value):
 Line 184: Change elif [ $_VER -eq 70 ] to elif [ $_VER -eq 74 ]
 as well as the tweaks.sh file, as follows: 
 Line 159: Change elif [ $_VER -eq 70 ] to elif [ $_VER -eq 74 ]
 Line 161: Change if [ $_VER_EXT -le 100 ] to if [ $_VER_EXT -le 324 ]
 Line 653: Change if [ $COMPAT_GROUP -ne 6 ] || [ $CMU_VER -ne 70 ] to if [ $COMPAT_GROUP -ne 6 ] || [ $CMU_VER -ne 74 ]
 🔴 Unknown if this works on V59. I was never on v59. If you can upgrade your v59 to v70 I would do that now.

 Installing Ameridan’s MazdaToFiatV70AIO.zip to Version 74 also requires some minor edits to the tweaks.sh file to allow for version 74, otherwise it will refuse to install.
 Using a proper text editor (such as NotePad++ which is my recommendation) edit the following:
 Line 159: Change “elif [ $_VER -eq 70 ]” to “elif [ $_VER -eq 74 ]”
 Line 161: Change “ if [ $_VER_EXT -le 100 ] ” to “ if [ $_VER_EXT -le 324 ] “
 Line 653: Change “if [ $COMPAT_GROUP -ne 6 ] || [ $CMU_VER -ne 70 ]” to “if [ $COMPAT_GROUP -ne 6 ] || [ $CMU_VER -ne 74 ]
 As you can see all that is changing are the numeric values. There are probably more elegant ways of changing this if making a distributable file, but this is the most expedient if you just need to install.
 —-
 In addition to the edit in run.sh from Mazda Tweaks 2.8.6 changing “elif [ $_VER -eq 70 ]” to “elif [ $_VER -eq 74 ]” these are the only changes needed to the two scripts.
