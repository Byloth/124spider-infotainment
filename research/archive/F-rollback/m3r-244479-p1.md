## [Tristan-cx5] 2023-03-01 (post 2549102)
Yes. If you update, you have to install them again (some few will remain, but I do not know which) - and this only applies for FW up to/including 70.00.100 (https://www.amazon.com/s?ascsubtag=v1-7532e0-244479-ab2f02f56d-k&k=Mazda+firmware+update&tag=vs-pl-mazda3revolution-com-20&rel=nofollow) and if you install the ID7/Autorun tweak from AIO (https://www.amazon.com/s?ascsubtag=v1-7532e0-244479-56497ff4c2-k&k=MZD-AIO+tweak&tag=vs-pl-mazda3revolution-com-20&rel=nofollow) before the update. If you update to a higher FW 70 or 74 all tweaks are gone.
