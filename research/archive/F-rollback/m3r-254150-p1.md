## [Tristan-cx5] 2025-06-09 (post 2584213)
My ideas/answers:
1. Might be - see the thread "Black Screen MZD (https://www.amazon.com/s?ascsubtag=v1-7532e0-254150-74ccafc335-k&k=MZD+Connect&tag=vs-pl-mazda3revolution-com-20&rel=nofollow)".
2. No, as the failed firmware install is located inside the old CMU (https://www.amazon.com/s?ascsubtag=v1-7532e0-254150-a6271e8131-k&k=cmu+Mazda3&tag=vs-pl-mazda3revolution-com-20&rel=nofollow).
3. If 1. does not work or is too complicated, a replacement would work.
As far as my many tests revealed, you could use any used unit from another car - also another series - e.g. CMU of a Mazda 3 for your Mazda 6. The CMU mainly reads the input it gets from other modules. And the latest new versions of the CMU have the same part no. for all models/series.
It does not have to be exactly the same part number.
Depends on the country and where you buy it - you have to check your available sources. New might be around 1000-1200 €. Used might be around 400-600 €.

## [Tristan-cx5] 2025-06-10 (post 2584250)
1. Yes, plugs are the same. As long as we are talking about the MZD (https://www.amazon.com/s?ascsubtag=v1-7532e0-254150-74ccafc335-k&k=MZD+Connect&tag=vs-pl-mazda3revolution-com-20&rel=nofollow) 1 and not any newer Generation.
2. Firmware version does not matter. It will work with any. Exception: If you have a new usb hub (https://www.amazon.com/dp/B0FVS8XLY5?ascsubtag=v1-7532e0-254150-324a3f3fd2-d&tag=vs-pl-mazda3revolution-com-20&rel=nofollow) for Android Auto (https://www.amazon.com/s?ascsubtag=v1-7532e0-254150-a6ccf0c1a6-k&k=android+auto&tag=vs-pl-mazda3revolution-com-20&rel=nofollow)/Apple Carplay (https://www.amazon.com/dp/B0FVRTCFBN?ascsubtag=v1-7532e0-254150-82052da475-d&tag=vs-pl-mazda3revolution-com-20&rel=nofollow) installed already, then the new CMU (https://www.amazon.com/s?ascsubtag=v1-7532e0-254150-a6271e8131-k&k=cmu+Mazda3&tag=vs-pl-mazda3revolution-com-20&rel=nofollow) has to have FW 70.00.021 (https://www.amazon.com/s?k=70.00.021&tag=vs-pl-mazda3revolution-com-20&rel=nofollow) or higher - for the new usb hub (https://www.amazon.com/dp/B0FVS8XLY5?ascsubtag=v1-7532e0-254150-324a3f3fd2-d&tag=vs-pl-mazda3revolution-com-20&rel=nofollow) to work.
