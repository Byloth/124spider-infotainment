## [?] 2020-12-29 (post 2502722)
I found 3 different options:
SSH connection via usb-ethernet-adapter: Use e.g. WinSCP to browse to /jci/version.ini and copy&open it - in there are the firmware version info located. More details see this post: Stuck in an installation loop from V.59 to V.70 (https://www.mazda3revolution.com/threads/stuck-in-an-installation-loop-from-v-59-to-v-70.242133/post-2502342)
Serial connection: Show firmware version in Putty - see details in this post: Stuck in an installation loop from V.59 to V.70 (https://www.mazda3revolution.com/threads/stuck-in-an-installation-loop-from-v-59-to-v-70.242133/post-2502391)
Serial connection: Copy /jci/version.ini (with firmware version in it) to a FAT32 formatted usb stick to later read the file content - see details in this post: Stuck in an installation loop from V.59 to V.70 (https://www.mazda3revolution.com/threads/stuck-in-an-installation-loop-from-v-59-to-v-70.242133/post-2502651)
I would recommend option 3.
