Garrett, I found this:
"Wireless CP requires special hardware inside the CMU. It is not just a software solution, even if both new CMUs part numbers (with and without CP) have the same firmware. So it is about the same as with wired CP/AA (same firmware, but requires hardware to be activated). You can not activate Wireless CP in a CMU which does not have the wireless CP hardware in it."

I don't think you can intercede with id7 on this version, so I don't believe you are going to be able to customize. I honestly don't know why you need to upgrade to this version?
