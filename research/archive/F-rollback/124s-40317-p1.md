## [kd215] 2021-09-30 (post 571870)
Well, I got it working. I started over with a CMU out of a 2018 124 Spider (https://www.amazon.com/s?ascsubtag=v1-d7c676-40317-901bb0ceef-k&k=Fiat+124+Spider&tag=vs-pl-124spider-org-20&rel=nofollow) (thank you, eBay!). I removed my bricked CMU, swapped in the replacement, and verified it was working. I also verified it was running system software version 56.00.530. I then followed these steps, just as I did on my first attempt:
1. Install the ID7 autorun script (preserves the ability to install tweaks after upgrading system software to later versions)
2. Install Mazda (https://www.amazon.com/dp/B00P2P3HCQ?ascsubtag=v1-d7c676-40317-9a046660ab-d&tag=vs-pl-124spider-org-20&rel=nofollow) system software 70.00.100 following Mazda (https://www.amazon.com/dp/B00P2P3HCQ?ascsubtag=v1-d7c676-40317-9a046660ab-d&tag=vs-pl-124spider-org-20&rel=nofollow) procedure (enables CarPlay and Android Auto)
3. Install Universal Mazda (https://www.amazon.com/dp/B00P2P3HCQ?ascsubtag=v1-d7c676-40317-9a046660ab-d&tag=vs-pl-124spider-org-20&rel=nofollow)-to-Fiat (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) Version 70 AIO Tweak package (replaces Mazda (https://www.amazon.com/dp/B00P2P3HCQ?ascsubtag=v1-d7c676-40317-9a046660ab-d&tag=vs-pl-124spider-org-20&rel=nofollow) logos and animations with Fiat (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) or Abarth (https://www.amazon.com/s?ascsubtag=v1-d7c676-40317-e78673638c-k&k=Abarth+124+Spider&tag=vs-pl-124spider-org-20&rel=nofollow) ones, and re-enables CMU Nav functionality following v70 firmware upgrade)
Now, here is where I made a mistake on my first attempt. Previously, I followed the steps above by running Ameridan's AIO v1.51 tweaks package. DO NOT RUN THE AIO V1.51 TWEAKS PACKAGE AFTER UPGRADING TO V70.00.100 FIRMWARE. THAT'S WHAT BRICKED MY PREVIOUS CMU. Instead, use the AIO v2.8.6 (or later) available from www.mazdatweaks.com (http://www.mazdatweaks.com). The MZD-AIO-TI v2.8.6 software is compatible with v70.00.100 firmware. The AIO v1.51 available at Ameridan's blog is only compatible with v59 and earlier firmware (he has a list on his blog of the specific firmware versions that are tested compatible). Using the MZD-AIO-2.8.6 package, I was able to successfully remove the nanny warning on startup, and the reverse camera display warning label, and more importantly, enable use of the touchscreen while moving. And I didn't break anything in the process. I also retained the Abarth logos and animations.
FWIW, the eBay CMU I used cost me $285 with shipping, and came with the display still attached. Swapping it out was quick and easy, and required removing only one bolt (the 10mm bolt holding it into the dash).
