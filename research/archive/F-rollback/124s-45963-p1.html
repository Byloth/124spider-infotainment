I've found a changelog of all CMU versions and pasted it below. RED NOTES ARE MINE.

Please keep in mind, most people who upgrade to V70 are using 70.0.100 - not the later versions - therefore those fixes are not in their V70. So even though V74 fixes fewer items itself, it includes many later V70 fixes that the common V70 versions don't include.

DESCRIPTION: Latest to Original Version of Firmware for all GENERATION-6 Mazda MZD-CONNECT.
Some vehicles may experience the symptoms mentioned below, which can be fixed with the latest software update:

• Updating MAZDA CONNECT to the latest version will erase/remove any customization created by unauthorized software like AIO.
• Unauthorized customization software like AIO will not work on the latest version of MAZDA CONNECT software.

• The latest version of MAZDA CONNECT software cannot be rolled back to an earlier version.
• Mazda does not recommend unauthorized customization of MAZDA CONNECT due to the possibility of unexpected problems. Any issues related to this will not be covered under Mazda warranty policy.
The system performance has been improved as follows:

Ver. 74.00.324A fixes ALL these software errors (bugs) below from Version 55.00.650 to 74.00.324A:

• If the shift lever is operated quickly while displaying the CarPlayTM screen, the rear view screen may not return to the CarPlayTM screen.
• When the gear position is shifted into P from R, the screen may not return to the previous condition before shifting into the R position.

Ver. 74.00.311 fixes these software errors (bugs):
• When using CarPlayTM, sound may not come out from the driver side speaker.

Ver. 74.00.310 and later fixes these software errors (bugs):
• Frequent temperature warnings may appear in the center display.
• The time in the center display may be inaccurate.

(SiriusXM cannot be selected, only certain channels appear in the list, the sound turns off and/or the center display shows an error message such as “Check SiriusXM Tuner” or “Unable to Connect to SiriusXM Radio”.)

• Country information (such as alcohol limit etc.) in the navigation screen may not be correct.
To correct, the country information has been removed in the latest version.

Installing Ameridan’s MazdaToFiatV70AIO.zip to Version 74 also requires some minor edits to the tweaks.sh file to allow for version 74, otherwise it will refuse to install.

Using a proper text editor (such as NotePad++ which is my recommendation) edit the following:

Line 159: Change “elif [ $_VER -eq 70 ]” to “elif [ $_VER -eq 74 ]”

Line 161: Change “if [ $_VER_EXT -le 100 ]” to “if [ $_VER_EXT -le 324 ]“

Line 653: Change “if [ $COMPAT_GROUP -ne 6 ] || [ $CMU_VER -ne 70 ]” to “if [ $COMPAT_GROUP -ne 6 ] || [ $CMU_VER -ne 74 ]

As you can see all that is changing are the numeric values. There are probably more elegant ways of changing this if making a distributable file, but this is the most expedient if you just need to install.

There's numerous advantages (as shown in the changelogs) for running V70.00.xxx software, with the much improved USB hub, over v56.00.xxx with the old hub. Specifically there are a lot of bluetooth and system stability fixes.

However, the differences between v70 and v74 are far less compelling. Whilst there's still some fixes, none are as "fundamental". I have cars running both v70 & v74 (using Fiat Nav coding, tweaks etc.) and can't say there's any real advantage to v74.The relative hassle of steps needed to be able to install custom code onto v74 also makes it unappealing as something to recommend from a support perspective.
