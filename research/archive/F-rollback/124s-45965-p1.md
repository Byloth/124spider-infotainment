we are now able to run any script on the CMU even with the "locked" versions. This includes the MazdaToFiatV70AIO conversion, and the Mazda Tweaks 2.8.6!
This means you can have V70, without ID7 and without any serial connection needed updated to Fiat/Abarth branding, with FIXED NAVIGATION. I have done this on my own CMU in my 2017 124 Spider that did not have id7 and it works.
Use the method in Post 142 to run any script on your thumb drive.
Tools Needed:
1 thumbdrive.
1 usb keyboard.
(Maybe need the upgraded USB port? Not sure, haven't tried the keyboard on the old USB port)
Steps:
1) Prepare your USB drive (formatted FAT32) with the contents of GitHub - mzd-evo/mzd-connect-1-root (https://github.com/mzd-evo/mzd-connect-1-root) (copy the contents of the folder in the zip to the usb drive root)
2) ALSO copy the contents of your MazdaToFiatV70AIO.zip file to the root of your USB drive. Yes you're mixing files.
3) Boot up your bland Mazda firmware radio.
4) Insert thumb drive and keyboard.
5) Set Audio Source to USB1. It will "play" the mp3 files on the thumb drive. Hint: They're not really MP3 files. It's a payload to launch the debug screen.
6) You should see a white screen on the left, and then a minute later a black popup dialog. If you don't get the popup, tap on "Open Terminal" (not sure if this step is needed). On the black popup, select "Terminal". You may need to click "Next" first to get that option.
7) Now a hard to read terminal screen opens. The directions in the linked post didn't work for me as it didn't want to run the script as described. Following is what worked for me:
8) On your USB keyboard type exactly and hit enter after each:
cd /mnt​cd sdb1​./tweaks.sh​9: Now it will give you some missing directory errors and spam your screen. Don't worry. It will soon pop up with the standard MazdaToFiatV70AIO menu and you're off to the races! From this point follow the direction on Ameridan's blog to answer the following questions. When it reboots you can remove the thumb drive!
What Next:
A) You can run the Mazda Tweaks 2.8.6 the same way! Just copy the mzd-connect-1-root files to the thumb drive, and overlay those files with the contents of the _copy_content_to_root_of_fat32_usb_stick folder, overlaying those. Then run the tweaks.sh from that as well.
B) This method also works with v74, so if you had upgraded to that and found you couldn't downgrade, here's your sign... I mean, your fix.
C) Unknown if this works on V59. I was never on v59. If you can upgrade your v59 to v70 I would do that now.

## [madfiat] 2025-05-26 (post 647069)
The V70 install doesn't require the hack. I'm pretty sure you can always upgrade the firmware through the normal upgrade steps. The issue is that without id7 or this hack, you would have lost the ability to tweak, including fixing the Fiat (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) branding and fixing the NAV. If you are already at v59 or above without id7, then the MP3 hack will allow you to modify whichever version you have without needing id7 or serial.
So really the order of ops is:
1) If you are still at an older version, use the normal steps to UPGRADE to the newer version with AA/CarPlay (https://www.amazon.com/dp/B0FQTSRKBM?ascsubtag=v1-d7c676-45965-679dae7c89-d&tag=vs-pl-124spider-org-20&rel=nofollow). Serial hack, nor mp3 hack not required for upgrades.
2) Now swap your hardware once you have v70 (before continuing to run any of the tweaks)
3) Once installed, if you were unable to do id7 (due to having v59 or newer already, or messing it up/forgetting), then you can use the MP3 hack now to restore your missing log/NAV and do other tweaks.
4) Prepare thumb drive by copying the MP3 hack to the thumb drive, AND copying the MZD to FIAT (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) files to the thumb drive.
5) Insert thumb drive and set Audio Source to USB. The radio will auto load the hack, and bring up the diagnostic screen, from where you will choose the terminal. It takes a few moments for the menu to load allowing you to choose the terminal.
6) From the terminal screen, with a USB keyboard detected, you manually run the script (tweaks.sh for the mazda (https://www.amazon.com/dp/B00P2P3HCQ?ascsubtag=v1-d7c676-45965-9a046660ab-d&tag=vs-pl-124spider-org-20&rel=nofollow) to Fiat (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) file). Once the script runs it will install the modified files the same as Ameridan's blog explains.
7) To do further tweaks, you then prepare your USB with the same MP3 hack files, and then overlay the folder from the Mazda (https://www.amazon.com/dp/B00P2P3HCQ?ascsubtag=v1-d7c676-45965-9a046660ab-d&tag=vs-pl-124spider-org-20&rel=nofollow) tweak utility, and instead run the script "run.sh".
Specific answers to your questions:
1) No, you would install the V70 firmware before doing the hack as a separate step following Mazda (https://www.amazon.com/dp/B00P2P3HCQ?ascsubtag=v1-d7c676-45965-9a046660ab-d&tag=vs-pl-124spider-org-20&rel=nofollow)'s directions in the PDF file linked on Ameridan's blogs.
2) The MP3 hack is done after you have a fully working V70 (or in theory V74) firmware. (Yes, you need the USB keyboard at this time).
3) V70 should already be installed prior.
4) Yes you install the AIO after v70.
5) Yes you need to do a reboot. between installation of V70 (which you do the old way), and then after the MZD to FIAT (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) file. The first reboot seemed to take a little bit longer.
6) After you've done the MZD to FIAT (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) then you repeat the same process (after a reboot) with the files from the Mazda (https://www.amazon.com/dp/B00P2P3HCQ?ascsubtag=v1-d7c676-45965-9a046660ab-d&tag=vs-pl-124spider-org-20&rel=nofollow) AIO. Make sure to use "run.sh" option when building the files as this gives the script you need to run.
7) You should be able to see Carplay (https://www.amazon.com/dp/B0FQTSRKBM?ascsubtag=v1-d7c676-45965-679dae7c89-d&tag=vs-pl-124spider-org-20&rel=nofollow). In theory this became available after step 1. What you need the Mp3 hack for is to enable tweaks, restore Fiat (https://www.amazon.com/s?k=Fiat&tag=vs-pl-124spider-org-20&rel=nofollow) branding, and restore factory NAV. Also in theory it would let you downgrade the firmware, however this shouldn't be necessary anymore since we can tweak.
8) You can (and maybe should) install the new USB Hub as soon as you have finished the initial V70 install, before you run the scripts

## [madfiat] 2025-05-31 (post 647315)
LS can't be capitalized, must be lower case.
If ls in the /mnt directory does not show something like sdb1 or sdb2, etc, then your USB is not formatted correctly.
Your USB must be formatted as FAT32. If it is larger than 32GB, windows will default to exFat or NTFS, neither of which will work. You'll need a smaller USB drive, formatted as FAT32. (There is a way to use a larger drive, but it involves more complex preparation to ensure FAT32 formatting). Also, I've heard that MAC formatted drives won't work either.
