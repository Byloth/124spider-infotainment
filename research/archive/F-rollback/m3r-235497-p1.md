## [Tristan-cx5] 2019-07-09 (post 2458947)
@Albuyeh (https://www.mazda3revolution.com/members/albuyeh.158185/): According to ASH8, who often posted the official Mazda guidelines to their dealers, you can (and as a dealer have to) update as follows:
FW < (smaller than) 31.00.100A has to be updated to FW 31.00.100A first.
FW >= (equal or higher) 31.00.100A has to be updated straight to the latest FW, which currently is 70.00.335.
This is fact/knowledge and not believing/guessing. That`s why ASH8 moved all FW versions in between to the "outdated" folder.
For sure you can install any version in between, which is available at the hidrive server - and your recommendation regarding tweaks is correct. But then I would add the recommendation not to install FW 70.00.335, but 70.00.100, as .335 removes the ID7 tweak from AIO - but that`s a topic in another thread - see ID7v2-thread (https://mazda3revolution.com/forums/2014-2018-mazda-3-skyactiv-audio-electronics/234619-id7-recovery-v2.html). And tweaks were not requested here.
 @Angel Moreno (https://www.mazda3revolution.com/members/angel-moreno.547647/): Have you verified the hashes of your downloads? If they are corrupt (hashes of your downloaded files do not match the ones mentioned in the files at the server), you can try as many usb sticks as you want and it will never work. Then you have to download the FW files again and check hashes again.
