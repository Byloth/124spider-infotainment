Yes, if you can read the full ROM and write back to it you can assume it's working. 
Now i didn't know on the Linux side but take that bin file over to an ASCII reader (i just use Neoprammer for win) and look for text in address 7E0000 you should see something like cmu150_NA_74.....up as example which is the current file ran to update the system. You use address 10000 to flip the bit to start the update process and skip boot of the CMU. 
If you see 7e0000 you probably can consider that at l least the bin file wrote good or partly good back to the ROM.
Bin files also can get corrupted and choose a bad write too, i forgot to mention that.
