## [AnClar] 2022-01-23 (post 580744)
Yes. Just make certain to install the id7 patch first, before you do anything else. Luckily, with v56 you can install id7v1 via the USB port. id7 will preserve your ability to install tweaks via the USB port, as long as you don't update the system software beyond v70.00.100 NA N for North America.. For the rest...just follow the instructions here (https://21stcenturyfiat124spider.wordpress.com/2019/02/18/universal-version-70-fiat-tweak/#how-to) . Important to follow all the steps in order exactly as written. Skipping steps or doing them out of order can easily result in a bricked system.
