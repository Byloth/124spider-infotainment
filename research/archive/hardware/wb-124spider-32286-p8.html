Apple CarPlay on a 2019 Abarth with Navigation and 59.00.524 Firmware

I am going to attempt an upgrade to CarPlay on my 2019 124 Spider Abarth, and just want to be sure I understand all the steps I need to complete.

I am currently running:
Firmware version 59.00.524
Factory Navigation

My Requirements:
Maintain Navigation Features
Maintain FIAT specific software (icons, animations, etc.)

From what I understand, I need to perform the following steps:

1) Order the retrofit kit (Part# 0000-8F-Z34)

2) Order a USB-to-serial adapter

3) install ID7 tweak via a serial connection using instructions at Serial Connection - This is version 2.8.6 if I am not mistaken (MZD-AIO-TI_Setup_2.8.6.exe)

4) upgrade from firmware version 59.00.424 to Mazda V70.00.100NA N firmware

5) install MazdatoFiatV70AIO to “re-Abarthize” the system

5) Install the new hardware (I have the dash apart for the serial connection anyway…)

Can I get an AMEN?
