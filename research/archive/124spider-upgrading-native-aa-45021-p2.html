Upgrading to Native AA version from V56 tweaks AA

Jump to Latest

So couple years ago I installed the tweaks version of Android Auto on my 2017 head unit. It's been... well.. it works. Slow as heck, buggy and crashy with audio routing issues.

So... I bought the upgrade plug required to upgrade to the newer firmware with native Android Auto, but never actually got around to doing it.

Now I need to replace the screen (has the delamination issue), and figured "while I'm in there"... but have a couple questions.

Is there anything I need to do, since I have the hacked version of v56, before I install the updated firmware for native Android Auto? It's been a while since I did it. I remember having to do something with the boot loader? With a thumb drive? Does any of that stuff need to be "undone" or do I just do the standard install, and it'll blow away the tweaks?

I had 56.00.530 firmware and upgraded my CMU with "tweaks." I also installed a "backdoor" tweak (called "ID7 autorun") after that upgrade, which will allow me to use AIO to install tweaks again. Android Auto (AA) tweak has been released specifically for version 70, so my CMC should be ready. To be honest, I prefer to upgrade the USB hub with a wireless hub from AliEx.
