All those tweaks will work, but I am speaking specifically about the AA packages.

Within AIO Tweaks 1.51 is AA version 1.13 which is full of bugs.
There is a later version of AA 1.14b for firmware 56 and 1.15 for firmware 59+ which is not available via the tweaks package. It's too much of an explanation for here but suffice to say you need AA Tru_Go 1.14b which you flash via USB and is the latest for firmware 56.

Trust me..................I've been through all this myself. Flash the earlier AA 1.13 if you wish as it will work, but it is buggy. AA Tru-Go 1.14b can be flashed as a standalone package.
