@spamwax
Case 1. Fw59.00.502 to fw70.00.100 uses id7 (XX files) recovery package and method 1-11. That is id7 code can be applied anytime after the fw has been installed through a serial connection to gain full root access and the ability to install tweaks from an usb flash drive afterwards.

Case 2. (Which is your case) firmware version from 70.00.335-> fw70.00.352 must use id7v2 (XX files). You must apply the code directly at the end of your fw installation to gain full root access otherwise you will not able to install tweaks from usb afterwards and must re-install the fw again and repeat the process. See link for how to

Serial Connection - CMU 2T connection not working

Thanks in advance for any assistance! I have tried many times to have the serial connection done to enable AIO in my 70XX CMU. Tested USB with TX connected to RX is working on Putty. This comes down to the wiring connection between the USB adapter and the CMU. For RX port I can receive (text)...
www.mazda3revolution.com

Do not get confused with id7 (XX files), id7v2 (XX files) or combine them and the corresponding fw that associated with the methods to gain full root access. For both cases fw and XX files must be in the same usb drive (less than 64GB) FAT32 formatted. XX folder must be in the usb root directory.

  • Are you sure, that you downloaded the correct XX file, as it is not online anymore since at least 2 month. Here you can find the file, which was originally at the website: AIO Tweaks and Firmware Ver .502- READ THIS
  • Copy cmu150_NA_70.00.335C_update.up to the root of the USB, NOT in the XX folder.
  • Correct, insert the USB drive in one of the car's USB slots, not the computer.
  • Correct, you can update 335C firmware over the same 335C firmware. Or you update to .352.
  • "After the update applies the text will stop and I can run the cp -r /mnt/sd*/XX/* /mnt/data_persist/dev/bin/; chmod +x /mnt/data_persist/dev/bin/autorun; /mnt/data_persist/dev/bin/autorun command?" -> correct - see e.g. this thread for detailed screenshots: ID7 Recovery v2
  • ""Make a tweaks installer with AIO and test." Need more details here. Does this mean run AIO and choose the tweaks to install, compile, and add the files to USB?" -> correct. "Do I start with an empty USB or add it to the existing XX folder?" -> I would recommend that. "How do the tweaks get installed?" -> compile AIO tweaks, copy them to the usb stick, insert the usb stick to the car`s usb slot, start engine or ACC and wait -> popups at the display will guide you / the installation will start automatically.
  • I've seen references to newer 74.00.230 firmware. Should I upgrade? -> Not if you want to use AIO tweaks, as this version can not be enabled to install AIO tweaks - with ID7v2 process this is only possible for .335 and .352.
Hope these answers help?

Success! Thanks for your help. The sequence for 335 (and 352) is:

  • Pull the dash apart to get to the CMU.
  • Connect a serial cable and ground to CMU.
  • Open Putty with baud rate 115200 on the correct serial port. Data will scroll by. TIP: If data is not scrolling, try turning the car to ACC - the CMU may have gone to sleep.
  • Copy 70.00.335 or .352 firmware to a USB key and insert in car.
  • Turn car to ACC mode.
  • Press and hold Music + Favorites + Mute to get to the control menu.
  • Press 2, ENTER. Press 3, ENTER.
  • Press 99, ENTER to upgrade or reinstall .335 or 352 firmware. Installation will take about 30 minutes. IMPORTANT: Press clutch at 20 minutes to prevent car from going to sleep.
  • At the end of the update the text will stop scrolling in Putty.
  • Paste cp -r /mnt/sd*/XX/* /mnt/data_persist/dev/bin/; chmod +x /mnt/data_persist/dev/bin/autorun; /mnt/data_persist/dev/bin/autorun in Putty. It will finish when you see a # prompt.
  • Turn the car off. Now the car is able to install the tweaks from the USB key.
  • Reformat the USB key, run AIO to pick the tweaks you want to install, and copy them to the USB key.
  • Insert the USB key with the tweaks in the car and turn it on. In a minute it will read the USB key and offer to install the tweaks.
This will continue to work until you upgrade or reinstall the firmware.

Hope this helps.
