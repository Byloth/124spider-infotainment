Regardless of whether you're doing the Carplay/AA Hardware upgrade or not, install the patch while you're still in v56, while you still can. There is no reason not to. It will allow you to retain the ability to update via USB port as well as installing AIO Tweaks(Mazda2Fiat rebranding included).

As far as staying in v56 or upgrading to v70- I'm sure there are possibly improvement updates on the later firmware, but the main reason you'd want to upgrade to v70 is because that's the version that supports Carplay/AA.

I guess it wouldn't hurt to upgrade to v70 if you wanted to, just make sure you install the patch beforehand.
